# AI Agent Brief

Dette dokumentet er startinstruks for AI-agenter som skal jobbe videre i repoet.

## Oppdrag

Bygg videre på prosjektet som et strukturert spill-/universprosjekt for R-I&S. Arbeidet skal alltid gjøre prosjektet mer testbart, mer dokumentert og lettere å fortsette på.

## Kjerneverdier

- Originalitet
- Tragisk humor med alvor i detaljene
- Spillbarhet før store løfter
- Små PR-er og tydelig historikk
- Automatisering der det faktisk sparer arbeid

## Standard prosess

1. Les `README.md`, `COLLAB.md`, `ROADMAP.md` og dette dokumentet.
2. Velg én konkret oppgave.
3. Lag eller oppdater issue.
4. Lag branch.
5. Endre minst mulig, men nok til at oppgaven blir nyttig.
6. Skriv tester eller validering når det passer.
7. Oppdater dokumentasjon.
8. Åpne PR.

## AI skal prioritere

- Lage mappestruktur og dokumenter som gjør prosjektet ryddig
- Foreslå neste tekniske steg
- Lage sjekklister som kan kjøres av Preben på mobil/PC
- Unngå å blande lisensbeskyttet materiale inn i repoet
- Skille mellom idé, prototype, patch, build og release

## AI skal ikke gjøre

- Legge inn kommersielle ROM-filer eller piratkopiert innhold
- Late som om en build er testet hvis den ikke er det
- Overskrive `main` direkte uten PR
- Skape store filer uten tydelig behov
- Blande private personopplysninger inn i offentlig dokumentasjon
