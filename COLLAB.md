# RIS / AI Collaboration Setup

Dette repoet brukes som arbeidsflate for videre utvikling med AI-assistert planlegging, kodearbeid, dokumentasjon og testing.

## Arbeidsprinsipp

1. **Issue først**: Alle nye ideer, bugs, kartendringer og features skal inn som GitHub Issues.
2. **Branch per oppgave**: Bruk `feature/...`, `fix/...`, `docs/...` eller `automation/...`.
3. **Pull request før merge**: Ingen større endringer direkte til `main`.
4. **Små leveranser**: Hver PR skal helst levere én konkret forbedring.
5. **Ingen ulovlige basefiler**: Ikke commit ROM-filer, dumpede spillressurser, private nøkler eller lisensbeskyttet materiale.
6. **Dokumenter idéopphav**: Nye konsepter, karakterer, universregler og ASTRA-9-notater bør dokumenteres i `docs/`.

## Fast AI-arbeidsflyt

Når videre arbeid startes, skal AI-agenten gjøre dette:

```text
1. Les README, COLLAB, ROADMAP og relevante docs.
2. Finn åpne issues med høyest verdi.
3. Del opp oppgaven i små filer/endringer.
4. Lag branch.
5. Endre filer.
6. Kjør tester/validering lokalt når mulig.
7. Åpne PR med kort oppsummering, teststatus og neste steg.
```

## Roller

- **Preben / R-I&S**: Idé, retning, godkjenning, originalt univers, stil og prioritering.
- **AI-agent**: Struktur, kodeforslag, dokumentasjon, automatisering, tester og PR-klargjøring.
- **GitHub**: Sann kilde for versjon, historikk, issues og pull requests.
